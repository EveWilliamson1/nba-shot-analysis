# NBA Shot Analysis 🏀

A collaborative statistical analysis project completed as part of my BSc Financial Mathematics degree at Cardiff University.

Using NBA shot data from the **2014–2015 season**, we explored how shooting performance varied across players and teams, and investigated relationships between player characteristics, salary and shooting behaviour.

## What we explored

- Differences in shooting performance between NBA teams and players
- Relationships between shot distance and shooting success
- Player characteristics and shooting behaviour
- Player salaries and team salary-cap data
- Statistical differences between groups and player categories

## Statistical Analysis

The project was completed in **R** and involved a range of statistical methods, including:

- ANOVA
- Chi-squared and proportion tests
- Correlation analysis
- Linear regression
- Kruskal–Wallis testing
- Data visualisation and exploratory data analysis

The analysis combined shot-level data with player information and salary data, producing a dataset of over **130,000 NBA shots**.

I particularly enjoyed working with a large real-world dataset and using statistical methods to turn individual shot records into interpretable comparisons between players and teams.
